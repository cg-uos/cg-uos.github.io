Animated Hexagonal Spline Reconstruction — Mh11, Mh20, V4

Every lattice coefficient below oscillates on its own sinusoid -- a randomly chosen minimum, maximum, speed, and phase per point -- and the spline reconstructed from them is re-evaluated every frame, entirely on the GPU: an optional FIR discrete quasi-interpolation (dQI) prefilter pass followed by the spline evaluation, both WebGPU compute shaders. (The factored IIR prefilter needs a sequential CPU recursion, so it has no place in a real-time GPU animation and isn't offered here -- see the companion static reconstruction demo for FIR vs. IIR2.) This page requires a WebGPU-capable browser (recent desktop Chrome or Edge).
