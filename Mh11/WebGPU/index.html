Hexagonal Spline Reconstruction Demo — Mh11, Mh20, V4

Hexagonal spline reconstruction with the following procedure.:

  1. Samples an analytic test function on the hexagonal lattice
  2. Spplies a discrete quasi-interpolation (dQI) prefilter
  3. Evaluates the reconstructed spline via WebGPU compute shaders
This page requires a WebGPU-capable browser (recent desktop Chrome or Edge).
